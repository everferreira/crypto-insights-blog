1. Onde rodar seus bots (o mais importante)

💻 VPS Linux 24/7 — o caminho profissional

Rodar automação no seu notebook tem um problema estrutural: quando ele desliga, seus cron jobs param — e perdem janelas de oportunidade. Uma VPS (máquina virtual na nuvem) resolve: fica ligada 24/7, com energia e internet estáveis.

Por que VPS > notebook disponibilidade contínua, IP dedicado, sem depender de você lembrar de deixar a máquina ligada.

Custo justo US$ 4-8/mês em planos entry (2 GB RAM é suficiente para Python + web3 + cron).

Requisito real Linux (Ubuntu/Debian), 1-2 vCPU, 2 GB RAM, 20 GB SSD.

👉 Ver VPS recomendada (Hostinger) — plano a partir de US$ 4/mês
👉 Alternativa (DigitalOcean) — droplets sob demanda

🖥️ Se quer começar no notebook primeiro

Perfeitamente válido para aprender e operar com valores pequenos. O que você precisa garantir:

  • Desligar o modo de suspensão (ou o cron "perde" os horários)
  • Redundância: jobs idempotentes que rodam em lote na volta
  • Backup do estado e do ledger

Quando migrar para VPS quando o volume de operações e o valor em jogo justificarem os US$ 4/mês.

2. RPCs: a rede de conexão dos seus scripts

Seu bot conversa com a blockchain via RPC. RPCs públicos são grátis mas caem (429/403). Para operação séria:

  • Rotação de RPCs públicos — padrão do nosso guia (grátis, primeira camada)
  • RPC dedicado privado — mais estável, com rate limit alto; justifica quando o bot opera com frequência
  • Node próprio — o padrão ouro, mas exige VPS robusta; overkill para automação pequena/média
👉 Ver provedores de RPC dedicado (Alchemy/Infura/Chainstack)

3. Exchanges para movimentar fundos

🏦 Onde converter e operar com liquidez

Para quem está no Brasil: a escolha da exchange importa para custo (spread), PIX e segurança. Sugerimos comparar:

  • Binance — liquidez global, PIX no Brasil, programa de indicação que paga % das taxas
  • OKX — alternativa forte, boas taxas, especialmente para operação via API
  • Exchanges brasileiras — mais simples para PIX, spread maior em geral

Para automação via API Binance e OKX têm APIs maduras (python-ccxt) — as brasileiras são limitadas nesse ponto.

4. Segurança dos seus fundos

🔐 Hardware wallet (o guardião final)

Se o valor em jogo crescer, uma hardware wallet (Ledger/Trezor) mantém a chave privada num chip físico — imune a malwares do computador. NUNCA guarde chave de valor alto em arquivo de texto.
