3. ESCOLHENDO A BLOCKCHAIN E A CARTEIRA CERTAS

Por que a Base?

A Base é uma rede Layer 2 da Ethereum criada pela Coinbase. Ela é ideal para quem está começando porque:

  1. Gas absurdamente barato: enquanto na Ethereum mainnet uma transação custa US$ 5-50, na Base custa centavos (às vezes 0,01 gwei = praticamente grátis)
  2. Ecossistema em crescimento: é um dos L2 com maior TVL (US$ 13+ bilhões em 2026)
  3. Airdrop potencial: a Base ainda não tem token próprio — a empresa já sinalizou que está "explorando" um. Histórico on-chain real pode se tornar elegibilidade
  4. DEXs maduras: Aerodrome (a maior), Uniswap, etc.

A carteira

Crie uma carteira nova (MetaMask ou Rabby). Regras de ouro:

  • Nunca compartilhe a frase-semente com ninguém
  • Crie a carteira diretamente no navegador oficial, não em site de terceiros
  • Use uma carteira dedicada para farming — não misture com o que você usa para outras coisas
  • Anote a frase-semente em papel, guarde em local seguro

Aportando

Envie uma quantia pequena primeiro (ex: R$ 10-20 de ETH), faça 2-3 transações de teste, e só depois aumente. O objetivo inicial NÃO é lucrar — é entender o fluxo sem dor.

4. O MOTOR DO FARMING: SWAPS AUTOMÁTICOS COM TAKE-PROFIT

O conceito central do nosso sistema é simples, mas poderoso:

┌─────────────────────────────────────────────────┐
│                 O CICLO DO FARMING               │
│                                                 │
│  1. Compre o token da DEX (ex: AERO na Base)    │
│     → swaps ETH → AERO todos os dias            │
│                                                 │
│  2. Quando o preço subir +12% do custo médio    │
│     → venda 15% automaticamente                 │
│     → ETH volta para a carteira                 │
│                                                 │
│  3. Com o ETH de volta, compre de novo          │
│     → ciclo se repete sozinho                   │
│                                                 │
│  Resultado: constância + lucro realizado +      │
│  histórico on-chain crescendo                   │
└─────────────────────────────────────────────────┘

Por que isso funciona:

  • Você acumula o token nativo da DEX (AERO) — que é literalmente o "petróleo" do ecossistema Base
  • O take-profit realiza lucro (não é só "valorização de papel")
  • O ciclo é autossustentável: o ETH gasto em gas é recuperado nas vendas
  • Cada transação soma ao seu histórico on-chain (crédito para airdrops futuros)

Vou te mostrar a lógica com código real que usamos. Não copie cegamente — entenda cada parte.

⚠️ SEGURANÇA: sua chave privada deve ficar em um arquivo criptografado local ou em variável de ambiente. Nunca em código versionado, nunca em chat, nunca em site.

Passo 3: O swap ETH → AERO

O fluxo completo tem 3 transações (da primeira vez):

  1. Wrap: ETH → WETH (token envelopado)
  2. Approve: autorizar o router a usar seus WETH
  3. Swap: WETH → AERO via Aerodrome

Depois da primeira vez, o approve fica "salvo" (approve infinito) e o fluxo vira 2 transações.

Passo 4: A lógica de decisão

O coração do robô é a função de decisão:

def decidir_swap(balanco_eth, reserva, preco_atual, gatilho, max_swap):
    """
    - balanco_eth: quanto ETH você tem
    - reserva: ETH que NUNCA é usado (para gas)
    - preco_atual: preço do token hoje
    - gatilho: preço acima do qual VOCÊ NÃO compra (não compra caro!)
    - max_swap: valor máximo por operação
    """
    disponivel = balanco_eth - reserva
    if disponivel <= 0:
        return None  # não tem folga, não mexe
    if preco_atual >= gatilho:
        return None  # preço alto, espera
    valor = min(disponivel * 0.40, max_swap)  # usa 40% da folga, limitado
    return valor

As 3 regras de ouro da decisão:
1. Sempre tem reserva — nunca zera o saldo (o robô precisa de gas para operar)
2. Nunca compra caro — se o preço passou do gatilho, espera
3. Tamanho limitado — sempre um máximo por operação (não vai all-in)

6. O SISTEMA DE TAKE-PROFIT QUE PROTEGE SEU CAPITAL

Comprar todo dia é bom, mas sem vender você nunca realiza lucro. O take-profit é o seu segurança.

Como funciona na prática

GANHO_MINIMO = 12   # % de ganho para vender
FRACAO_VENDA = 0.15 # quanto vender (% do saldo)

ganho = ((preco_atual / custo_medio) - 1) * 100

if ganho >= GANHO_MINIMO:
    vender(FRACAO_VENDA)  # vende 15% na alta
    custo_medio = preco_atual  # atualiza referência

Por que 12% / 15%?

  • 12% de gatilho é alcançável com frequência (volatilidade saudável) sem ser "ganho de formiga" (5%)
  • 15% de venda mantém 85% trabalhando — você nunca "mata a galinha"
  • Atualizar o custo médio após vender reinicia o ciclo na nova base

O erro clássico (que vimos na vida real)

Nosso sistema ficou travado durante semanas porque o custo médio registrado era de um período antigo (quando AERO valia mais) — o gatilho de +15% ficou a 22% de distância do preço atual. Correção: recalibrar o custo médio para o preço real de mercado das compras recentes. O sistema passou a capturar ciclos de novo.

Lição: custo médio errado = robô cego. Sempre recalibre quando o mercado andar muito.

7. MULTI-CHAIN: EXPANDINDO PARA OPTIMISM, ARBITRUM E SCROLL

Depender de uma chain só é fragilidade. O sistema real opera em várias:

Chain DEX Token Por quê
Base Aerodrome AERO O motor principal (ecossistema gigante)
Optimism Velodrome OP/VELO Gas quase zero, OP tem valor real
Arbitrum Camelot ARB Ecossistema maduro
Scroll (em avaliação) SCR/ETH Histórico adicional

Dica real: cada chain tem saldos pequenos separados. Configuramos reservas por chain — 0.0005 ETH na Base (gas um pouco maior), 0.00005 nas L2s (gas quase zero). Isso destrava saldos que ficariam "presos" esperando reserva grande.

Aprendizado honesto: na Optimism, o pool de VELO estava vazio (sem liquidez) — o robô reverteu. Trocamos para comprar OP (que tem liquidez real). Sempre simule a transação antes de enviar ('eth_call') — custa nada e evita gas queimado.

8. AIRDROPS: A LOTERIA QUE PODE MULTIPLICAR TUDO (E COMO SE QUALIFICAR DE VERDADE)

Airdrop é quando um protocolo distribui tokens grátis para usuários que usaram a plataforma antes do lançamento. Histórico: Arbitrum deu até US$ 10.000 por carteira, Optimism, zkSync idem.

Os grandes candidatos em 2026

  1. Base — explorando token oficialmente. O maior prêmio potencial
  2. Polymarket — POLY confirmado, mecânica não lançada
  3. MetaMask — programa de lealdade da carteira
  4. LayerZero — alocação comunitária futura

Como se qualificar DE VERDADE (anti-sybil, sem gambiarra)

  • Atividade real e consistente (semanas/meses, não 1 dia de pico)
  • Diversidade de protocolos: swaps, lending (Morpho, Moonwell), bridges, NFTs
  • Valores variados de transação (padrão de humano, não de bot)
  • Histórico no tempo (o tempo é o melhor filtro anti-sybil)

O que NÃO fazer: conectar carteira em sites aleatórios de "claim", aprovar contratos suspeitos, enviar ETH para endereços desconhecidos, comprar scripts de farm em massa (sybil detection te elimina).

9. AUTOMATIZAÇÃO TOTAL COM CRON JOBS (FUNCIONA 24/7)

O sistema roda sozinho via cron (agendador do Linux). A grade real de jobs:

A cada 30 min  → verifica gatilho de venda (reage rápido a picos)
02h/14h/22h   → autopilot: decide e executa farm sozinho
10h           → farm principal diário (Base)
11h e 17h     → multi-farmer: interage com 1 protocolo novo por vez
18h           → farm extra condicional (só se preço < gatilho)
a cada 2h     → take-profit de AERO
a cada 6h     → take-profit de OP (Optimism)
dom 15h       → swap de diversificação de DEX
08h           → airdrop hunter (busca oportunidades reais)
05h           → conteúdo automático (blog)

Princípio-chave: cada job é idempotente — rodar 100x é seguro, porque cada um tem suas condições de segurança (reserva, gatilho, saldo mínimo). Se algo falha, roda de novo na próxima janela sem dano.

10. A PARTE CHATA QUE NINGUÉM FALA: GAS, RPCS E ERROS COMUNS

Gas (o custo de cada transação)

  • Na Base/L2s: 0,001-0,01 gwei = centavos de real
  • Na Ethereum mainnet: US$ 5-50 = esqueça para farming pequeno
  • Sempre mantenha reserva de ETH para gas — o pior cenário é ter liquidez presa sem gas para movimentar

RPCs (os servidores que conectam seu robô à chain)

RPCs públicos caem, dão rate-limit (429) ou bloqueiam (403). A solução real:

RPCS = [
    'https://base.drpc.org',
    'https://1rpc.io/base',
    'https://mainnet.base.org',
    'https://base-rpc.publicnode.com',
]
# Rotação: tenta cada um até achar um que responde

Lições reais de erros que quebraram nosso sistema:

Erro Causa Solução
429 Too Many Requests Rate-limit do RPC Rotação de RPCs
403 Forbidden RPC bloqueando Reordenar RPCs estáveis primeiro
execution reverted Pool sem liquidez / slippage Simular antes (eth_call)
Swap travado Custo médio desatualizado Recalibrar custo médio
Jobs noturnos perdidos PC desligado Rodar em lote na volta (idempotência)

12. PERGUNTAS FREQUENTES

Q: Preciso de muito dinheiro para começar?
R: Não. R$ 20-50 é suficiente para entender o fluxo. Aumente conforme ganha confiança.

Q: Isso é seguro?
R: As transações são públicas e os contratos são audited (no caso de DEXs grandes como Aerodrome). O risco real é: token cair (risco de mercado) e você aprovar contratos maliciosos (risco de golpe — nunca aprove o que não entende).

Q: Quanto tempo por dia preciso dedicar?
R: Com o sistema automatizado: 0 minutos. O computador com os cron jobs faz tudo. Você acompanha 1x ao dia o relatório.

Q: E se o preço cair muito?
R: O sistema tem 3 proteções: reserva de gas (nunca zera), não compra acima do gatilho (não compra caro), e o take-profit vende na alta (nunca vende no pânico). Em queda forte, o robô simplesmente espera.

Q: Airdrop é garantido?
R: NÃO. É loteria com probabilidade melhorada por atividade real. Trate como bônus, não como plano principal. O plano principal é o farming com take-profit.

Q: Posso fazer tudo isso no celular?
R: O sistema como construímos precisa de um computador (para os cron jobs). O celular serve para acompanhar os relatórios.
